# 灯守の旅路 英語の章

冒険しながら英語の単語・熟語・文法・長文を練習できる、ブラウザで遊べるRPGです。

▶ 遊ぶ：https://kento1031-source.github.io/himori-eigo/

- スマホ・PCのブラウザで遊べます（インストール・登録不要・無料）。
- 敵が英語で問いかけます。正解すると攻撃、間違えると敵の反撃を受けます。
- 冒険の記録は自動で保存され、次に開くと前回の続きから始まります。記録は遊んでいる端末のブラウザの中にだけ保存されます。
- スマホでは「ホーム画面に追加」をすると、アプリのように開けて、記録も消えにくくなります（一度開いたあとは電波がなくても遊べます）。
- メニューの「セーブ」→「セーブコードを表示」で、冒険と英語の記録をまとめたコードを控えられます。機種変更のときは、タイトル画面の「コードで再開」から続きを遊べます。
- 練習できるのは英語を読む力（単語・熟語・文法・長文）です。聞く・話す・書く練習は含みません。
- 問題・文章・曲・絵はすべてこの作品のためのオリジナルです。特定の試験団体・教材とは関係ありません。学習の成果や試験の結果を保証するものではありません。
- 誤りの報告・お問い合わせ：kento.nocloud1031@gmail.com（問題の解説画面の「誤りを報告」からも送れます）
